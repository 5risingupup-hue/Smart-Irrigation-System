# 已验证模块接线

主控：**Arduino UNO R3**。已验证 SHT3X、OLED 共用 I²C，独立蜂鸣器由 D8 控制。

| 器件 | 模块端 | Arduino 引脚 |
| --- | --- | --- |
| SHT3X | VCC / GND | 5V / GND（当前模块已在此接法下测试） |
| SHT3X | SDA / SCL | A4 / A5 |
| OLED | VDD / GND | 已验证的模块供电 / GND |
| OLED | SDA / SCK | A4 / A5 |
| 高电平触发蜂鸣器 | VCC / GND / I/O | 5V / GND / D8 |

I²C 实测地址：`SHT3X = 0x44`，`OLED = 0x3C`。OLED 的 `SCK` 标注在这块板上对应 I²C 时钟 SCL。

> 面包板连通规则：中间沟槽两边分别为每行 5 孔连通，例如 a5–e5 相通；沟槽两侧不相通。具体孔位取决于实际摆放，**不要直接照看似真实但未经核对的生成接线图片通电**。

## 接线与供电注意事项

1. **每次改线先断开 USB 和 HW-131 电源。**
2. 当前温湿度与 OLED 供电以已验证的模块规格为准，不能把任何其他 3.3V 专用器件直接接 5V。
3. 面包板电源轨可能中间断开，需要确认连通情况；Arduino 5V 与独立水泵供电的 5V 不要并联。
4. **当前阶段没有接入水泵**。预计后续使用继电器控制 HW-131 的水泵电源，必须核对继电器触点 COM/NO、续流保护与水泵的启动电流。
5. 已观察充电宝可使 HW-131 通电，不代表 HW-131 已通过水泵启动负载测试。
